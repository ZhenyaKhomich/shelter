# 🐾 Shelter — Адаптивный сайт приюта для животных

**Shelter** — это адаптивный сайт для приюта животных, выполненный в рамках курса **RS School**.  
Проект реализован на **чистом HTML, CSS (SCSS) и JavaScript** без использования сторонних библиотек и фреймворков.

---

## 🌟 **Функционал проекта**

### ✔ Адаптивная вёрстка
- Поддержка трёх брейкпоинтов: **1280px**, **768px**, **320px**

### ✔ **Бургер-меню** на устройствах с шириной экрана `<768px`
- Плавное открытие и закрытие
- **Блокировка прокрутки фона** при открытом меню
- Клик вне меню закрывает панель
- **Анимация поворота иконки**

### ✔ **Бесконечный слайдер-карусель** на главной странице
- Плавная анимация смены слайдов
- Кол-во карточек зависит от ширины экрана (**3 / 2 / 1**)
- **Случайный набор карточек** без повторов в текущем и следующем слайде

### ✔ **Пагинация на странице Pets**
- **48 карточек** (каждый из 8 питомцев встречается 6 раз)
- Разное количество страниц в зависимости от ширины экрана (**6 / 8 / 16**)
- **Работает без перезагрузки** при изменении ширины экрана

### ✔ **Модальные окна (попапы)**
- Открываются по клику на карточку
- Закрываются по клику на **крестик** или **вне попапа**
- **Блокировка скролла** при открытом попапе

### ✔ **Генерация DOM-элементов из данных**
- Все карточки, попапы и слайды создаются **динамически**
- Используется массив с **8 объектами питомцев**
